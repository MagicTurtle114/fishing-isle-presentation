# Fishing Isle 釣魚小島 — 開發總結簡報

Roblox 釣魚遊戲《Fishing Isle 釣魚小島》從零開發到可玩核心版的完整回顧。

## 直接看

開 **[https://magicturtle114.github.io/fishing-isle-presentation/](https://magicturtle114.github.io/fishing-isle-presentation/)**

或在這個 repo 開 `index.html`。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `←` `→` | 翻頁（也可以直接點頁面往下一張） |
| `F` | 全螢幕 |
| `P` | 匯出成 PDF（`@page 1280×720`，一頁一張投影片） |

## 內容

15 張投影片，分四個部分：

1. **你回報的問題** — 共 17 項，分三輪回報，全部已修正並實測驗證
2. **根因分析** — 6 個「看到的症狀 vs 真正的原因」對照，例如圓柱軸向是本地 X 導致椰子樹橫躺
3. **開發中遇到的技術障礙** — 這個 Studio 版本缺的 8 支 API、注入沙箱限制、無法自行檢視圖片只能靠幾何驗證
4. **最終成果** — 4 座島、4 個魚域、6 艘船、12 種魚、1,055 個程式生成的實例、17 個 Remote、206 項自動化檢查全過

## 這個 repo 是什麼

只有這份簡報。遊戲的完整原始碼（`src/`、`config/`、`plugin/`、`install.ps1`、`README.md`）沒有公開，保留在作者端。

## 技術

單一 HTML 檔案，沒有任何外部相依，離線可看。版面固定 1280×720 設計尺寸再等比縮放，所以任何螢幕大小都不會跑版或被裁切。
